# نصب پکیج

Emacs به همراه خودش یک سیستم مدیریت پکیج به اسم `package.el` داره که بهت اجازه میده پکیج‌های اضافی رو از مخازن مختلف نصب کنی. توی این فصل قراره فقط با یک پکیج ساده از مخزن پیش‌فرض خود Emacs (GNU ELPA) کار کنیم تا با پروسه‌ی «تازه‌سازی مخزن» و «نصب پکیج» آشنا بشیم. در پایان هم مخزن MELPA رو اضافه می‌کنیم و یک پکیج سرگرم‌کننده به اسم `nyan-mode` رو نصب و فعال می‌کنیم.

جزئیات بیشتر و نوشتن یک `init.el` کامل رو می‌ذاریم برای فصل «شخصی سازی محیط».

## مخازن پکیج در Emacs

Emacs به‌صورت پیش‌فرض به مخزنی به اسم **GNU ELPA** وصله. این مخزن رسمیه و پکیج‌هایی که توش هست رو خود پروژه‌ی GNU بررسی و نگه‌داری می‌کنه. برای همینه که تعداد پکیج‌هاش نسبت به مخازن دیگه کمتره، ولی از نظر کیفیت و امنیت قابل اعتمادتره.

برای دیدن لیست پکیج‌های قابل نصب، این دستور رو بزن:

```
M-x list-packages
```

اولین باری که این دستور رو می‌زنی، ممکنه لیست خالی یا قدیمی باشه، چون Emacs هنوز فهرست پکیج‌ها رو از مخزن نگرفته.

## تازه‌سازی مخزن

برای اینکه Emacs فهرست آخرین پکیج‌های موجود در مخزن رو بگیره، باید مخزن رو «تازه‌سازی» (refresh) کنی. این کار رو می‌تونی به دو روش انجام بدی:

**روش اول:** توی بافر `*Packages*` (همون بافری که با `list-packages` باز شد) کلید `g` رو بزن.

**روش دوم:** مستقیم از طریق دستور زیر:

```
M-x package-refresh-contents
```

بعد از اجرای این دستور، Emacs یک اتصال به مخزن برقرار می‌کنه و فهرست پکیج‌ها رو دانلود می‌کنه. توی نوار پایین (minibuffer) پیام مربوط به دانلود رو می‌بینی.

## نصب یک پکیج از GNU ELPA

برای تمرین، پکیجی به اسم `sokoban` رو نصب می‌کنیم؛ یه بازی پازل کلاسیک که توش باید جعبه‌ها رو با هل دادن به جای درستشون برسونی.

### روش اول: با `list-packages`

اول `M-x list-packages` و بعد `g` برای تازه‌سازی. با `C-s sokoban` سرچ کن یا با اسکرول پیداش کن. روی خط پکیج، کلید `i` رو بزن (این پکیج رو برای نصب علامت می‌زنه) و در آخر کلید `x` رو بزن تا نصب بشه.
با `M-x sokoban` هم میتونی پکیج رو اجرا کنی.
### روش دوم: مستقیم با دستور

می‌تونی بدون باز کردن لیست، مستقیم بگی چه پکیجی نصب بشه(منظور از `RET` همون `ENTER` هست):


```
M-x package-install RET sokoban RET
```

### امتحان کردن پکیج

بعد از نصب، کافیه این دستور رو بزنی تا یک بافر جدید با بازی باز بشه:

```
M-x sokoban
```

با کلیدهای جهت‌دار (arrow keys) جعبه‌ها رو هل بده و توی جای مشخص‌شده (معمولاً با رنگ متفاوت) قرارشون بده. هر مرحله که تموم بشه، مرحله‌ی بعدی شروع می‌شه.

## اضافه کردن مخزن MELPA
Elpa مخزن کوچیکیه و اکثر پکیج های محبوب Emacs توی مخزنی به اسم Melpa هست و الان میخوایم MELPA رو اضافه کنیم.
برای این کار باید کد زیر رو به فایل `init.el` اضافه کنی:
برای رفتن به init.el:

```text
C-x C-f ~/.emacs.d/init.el
اگه فایل وجود نداشته باشه خود به خود ساخته میشه
```

```elisp
(require 'package)
(add-to-list 'package-archives
             '("melpa" . "https://melpa.org/packages/"))
(package-initialize)
```

بعد از اضافه کردن این کد به `init.el`:

- یا Emacs رو ری‌استارت کن
- یا کد رو انتخاب کن و با `M-x eval-region` اجراش کن
- یا کل فایل رو با `M-x eval-buffer` اجرا کن

حالا باید یک بار دیگه مخزن‌ها رو تازه‌سازی کنی تا فهرست MELPA هم دانلود بشه:

```
M-x package-refresh-contents
```

اگه دوباره `list-packages` رو باز کنی، می‌بینی تعداد پکیج‌های قابل نصب به شکل چشمگیری بیشتر شده.

## نصب و فعال‌سازی nyan-mode

`nyan-mode` یک پکیج کاملاً غیرجدی و سرگرم‌کننده‌ست: یک گربه‌ی رنگین‌کمانی (Nyan Cat) رو توی نوار وضعیت (mode-line) نشون می‌ده که موقعیتت توی فایل رو مثل یک نوار پیشرفت نمایش می‌ده.

نصبش دقیقاً مثل قبله، با این تفاوت که این بار از MELPA میاد:

```
M-x package-install RET nyan-mode RET
```

برای فعال کردنش:

```
M-x nyan-mode
```

اگه خواستی همیشه با باز شدن Emacs فعال باشه، این خط رو به `init.el` اضافه کن:

```elisp
(require 'nyan-mode)
(nyan-mode 1)
```

## جمع‌بندی

توی این فصل یاد گرفتیم:

- Emacs به‌صورت پیش‌فرض به مخزن **GNU ELPA** وصله
- برای دیدن و نصب پکیج از `list-packages` یا `package-install` استفاده می‌کنیم
- قبل از نصب، باید مخزن رو با `package-refresh-contents` تازه‌سازی کنیم
- برای دسترسی به پکیج‌های بیشتر، مخزن **MELPA** رو به `package-archives` اضافه می‌کنیم
- پکیج‌های نصب‌شده مثل `nyan-mode` رو می‌تونیم دستی یا از طریق `init.el` فعال کنیم

توی فصل بعدی («شخصی سازی محیط») سراغ یک `init.el` کامل‌تر می‌ریم و چند تا پکیج مهم‌تر و کاربردی‌تر رو هم نصب می‌کنیم.
