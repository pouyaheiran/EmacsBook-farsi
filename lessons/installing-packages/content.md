# نصب پکیج

ایمکس به همراه خودش یک سیستم مدیریت پکیج به اسم `package.el` داره که بهت اجازه میده پکیج‌های اضافی رو از مخازن مختلف نصب کنی. توی این فصل قراره فقط با یک پکیج ساده از مخزن پیش‌فرض خود ایمکس (GNU ELPA) کار کنیم تا با پروسه‌ی «تازه‌سازی مخزن» و «نصب پکیج» آشنا بشیم. در پایان هم مخزن MELPA رو اضافه می‌کنیم و یک پکیج سرگرم‌کننده به اسم `nyan-mode` رو نصب و فعال می‌کنیم.

جزئیات بیشتر و نوشتن یک `init.el` کامل رو می‌ذاریم برای فصل «شخصی سازی محیط».

## مخازن پکیج در ایمکس

ایمکس به‌صورت پیش‌فرض به مخزنی به اسم **GNU ELPA** وصله. این مخزن رسمیه و پکیج‌هایی که توش هست رو خود پروژه‌ی GNU بررسی و نگه‌داری می‌کنه. برای همینه که تعداد پکیج‌هاش نسبت به مخازن دیگه کمتره، ولی از نظر کیفیت و امنیت قابل اعتمادتره.

برای دیدن لیست پکیج‌های قابل نصب، این دستور رو بزن:

```
M-x list-packages
```

اولین باری که این دستور رو می‌زنی، ممکنه لیست خالی یا قدیمی باشه، چون ایمکس هنوز فهرست پکیج‌ها رو از مخزن نگرفته.

## تازه‌سازی مخزن

برای اینکه ایمکس فهرست آخرین پکیج‌های موجود در مخزن رو بگیره، باید مخزن رو «تازه‌سازی» (refresh) کنی. این کار رو می‌تونی به دو روش انجام بدی:

**روش اول:** توی بافر `*Packages*` (همون بافری که با `list-packages` باز شد) کلید `g` رو بزن.

**روش دوم:** مستقیم از طریق دستور زیر:

```
M-x package-refresh-contents
```

بعد از اجرای این دستور، ایمکس یک اتصال به مخزن برقرار می‌کنه و فهرست پکیج‌ها رو دانلود می‌کنه. توی نوار پایین (minibuffer) پیام مربوط به دانلود رو می‌بینی.

## نصب یک پکیج از GNU ELPA

برای تمرین، پکیجی به اسم `rainbow-mode` رو نصب می‌کنیم. این پکیج کدهای رنگ (مثل `#ff0000` یا `red`) رو توی بافر با همون رنگ نمایش می‌ده، پس اثرش کاملاً قابل مشاهده‌ست.

### روش اول: با `list-packages`

۱. `M-x list-packages` و بعد `g` برای تازه‌سازی
۲. با `C-s rainbow-mode` سرچ کن یا با اسکرول پیداش کن
۳. روی خط پکیج، کلید `i` رو بزن (این پکیج رو برای نصب علامت می‌زنه)
۴. کلید `x` رو بزن تا نصب اجرا بشه (execute)

### روش دوم: مستقیم با دستور

می‌تونی بدون باز کردن لیست، مستقیم بگی چه پکیجی نصب بشه:

```
M-x package-install RET rainbow-mode RET
```

### امتحان کردن پکیج

یک فایل جدید باز کن، مثلاً یک فایل CSS خالی، و این خط رو توش بنویس:

```css
color: #3498db;
```

بعد دستور زیر رو بزن تا حالت `rainbow-mode` روی همین بافر فعال بشه:

```
M-x rainbow-mode
```

باید ببینی که پس‌زمینه‌ی کد رنگ، با همون رنگ نمایش داده میشه.

> نکته: چیزی که الان نصب کردیم فقط برای همین یک نشست (session) فعاله. اگه ایمکس رو ببندی و دوباره باز کنی، پکیج نصب‌شده باقی می‌مونه ولی حالتش فعال نیست. توی فصل بعد یاد می‌گیریم چطور توی `init.el` هم نصب پکیج‌ها رو خودکار کنیم و هم فعال‌سازیشون رو.

## اضافه کردن مخزن MELPA

GNU ELPA مخزن کوچیکیه. اکثر پکیج‌های محبوب و پرکاربرد ایمکس توی مخزنی به اسم **MELPA** هستن. برخلاف GNU ELPA، MELPA به‌صورت پیش‌فرض به ایمکس اضافه نشده و باید خودمون معرفیش کنیم.

برای این کار باید کد زیر رو به فایل `init.el` اضافه کنی:

```elisp
(require 'package)
(add-to-list 'package-archives
             '("melpa" . "https://melpa.org/packages/"))
(package-initialize)
```

بعد از اضافه کردن این کد به `init.el`:

- یا ایمکس رو ری‌استارت کن
- یا کد رو انتخاب کن و با `M-x eval-region` اجراش کن
- یا کل فایل رو با `M-x eval-buffer` اجرا کن

حالا باید یک بار دیگه مخزن‌ها رو تازه‌سازی کنی تا فهرست MELPA هم دانلود بشه:

```
M-x package-refresh-contents
```

اگه دوباره `list-packages` رو باز کنی، می‌بینی تعداد پکیج‌های قابل نصب به شکل چشمگیری بیشتر شده.

## نصب و فعال‌سازی nyan-mode

`nyan-mode` یک پکیج کاملاً غیرجدی و سرگرم‌کننده‌ست: یک گربه‌ی رنگین‌کمانی (Nyan Cat) رو توی نوار وضعیت (mode-line) نشون می‌ده که موقعیتت توی فایل رو مثل یک نوار پیشرفت نمایش می‌ده.

نصبش دقیقاً مثل قبله، با این تفاوت که این بار از MELPA میاد:

```
M-x package-install RET nyan-mode RET
```

برای فعال کردنش:

```
M-x nyan-mode
```

اگه خواستی همیشه با باز شدن ایمکس فعال باشه، این خط رو به `init.el` اضافه کن:

```elisp
(nyan-mode 1)
```

## جمع‌بندی

توی این فصل یاد گرفتیم:

- ایمکس به‌صورت پیش‌فرض به مخزن **GNU ELPA** وصله
- برای دیدن و نصب پکیج از `list-packages` یا `package-install` استفاده می‌کنیم
- قبل از نصب، باید مخزن رو با `package-refresh-contents` تازه‌سازی کنیم
- برای دسترسی به پکیج‌های بیشتر، مخزن **MELPA** رو به `package-archives` اضافه می‌کنیم
- پکیج‌های نصب‌شده مثل `nyan-mode` رو می‌تونیم دستی یا از طریق `init.el` فعال کنیم

توی فصل بعدی («شخصی سازی محیط») سراغ یک `init.el` کامل‌تر می‌ریم و چند تا پکیج مهم‌تر و کاربردی‌تر رو هم نصب می‌کنیم.
