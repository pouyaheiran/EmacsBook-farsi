# نصب و راه‌اندازی

تا اینجا با خود Emacs و چند مفهوم مهمش آشنا شدیم.
حالا وقتشه بالاخره خود برنامه رو نصب کنیم و ببینیم
در عمل با چه محیطی طرف هستیم.

## قبل از نصب

Emacs روی سیستم‌عامل‌های مختلف اجرا می‌شود و روش نصب آن
به سیستم‌عاملت بستگی دارد.

در این آموزش تمرکز اصلی ما روی خود Emacs است، نه یک
سیستم‌عامل خاص؛ بنابراین اگر از Linux، macOS یا Windows
استفاده می‌کنی، روش مناسب سیستم خودت را انتخاب کن.

## نصب Emacs

### GNU/LINUX

اگر از یکی از توزیع‌های رایج GNU/LINUX استفاده می‌کنی،
می‌توانی Emacs را با package manager همان توزیع نصب کنی.

#### Debian / Ubuntu
  
    sudo apt install emacs

#### Fedora

    sudo dnf install emacs

#### Arch Linux

    sudo pacman -S emacs

اگر از توزیع دیگری استفاده می‌کنی، می‌توانی بسته‌ی `emacs`
را در package manager همان توزیع جستجو کنی.

### macOS و Windows

برای macOS و Windows هم می‌توانید Emacs را نصب کنید.

برای macOS، اگر Homebrew را نصب دارید:

    brew install --cask emacs

برای Windows هم می‌توانید Emacs را از صفحه‌ی رسمی GNU
دانلود و نصب کنید:

<a href="https://www.gnu.org/software/emacs/download.html"> صفحه رسمی </a>

<span style="color:#7F5AB6">
البته بعد از اینکه GNU به شما احساس ناکافی بودن داد
بخاطر استفاده از سیستم عامل غیرآزاد.
</span>

## اولین اجرا

بعد از نصب، Emacs را اجرا کن.

اگر میخواید به صورت غیر گرافیکی باهاش کار کنید میتونید
توی ترمینال اینجوری اجراش کنید:

    emacs -nw

در اولین نگاه ممکن است محیط Emacs کمی شلوغ یا حتی عجیب
به نظر برسد. فعلاً لازم نیست چیزی را تغییر بدید یا
تنظیمات خاصی انجام بدید.

فقط چند دقیقه محیط را نگاه کن و سعی کن چیزهایی را که در
بخش قبلی یاد گرفتیم پیدا کنی:

- Frame
- Window
- Buffer
- Minibuffer

## اولین هدف

فعلاً قرار نیست Emacs را شخصی‌سازی کنیم یا صدها تنظیمات
مختلف را تغییر بدهیم.

هدف این بخش فقط این است که Emacs روی سیستم تو اجرا
شود و بتوانی وارد محیطش شوی.

در بخش بعدی، اولین کار واقعی‌مان را انجام می‌دهیم:
یک فایل را در Emacs باز می‌کنیم، چیزی داخلش می‌نویسیم
و آن را ذخیره می‌کنیم.
