# Emacs چیست؟

## یک ویرایشگر متن؟

در ساده ترین حالت بله.

اما اگر قرار بود فقط یک text editor معمولی باشد،
احتمالاً دلیل خاصی برای یاد گرفتنش نداشتیم.

## پس چه چیزی Emacs را خاص می‌کند؟

مهم ترین ویژگی emacs اینه که میتونی اون رو تغییر بدی و قابلیت های جدید اضافه کنی.

بخش بزرگی از این قابلیت با **Emacs Lisp** انجام می‌شود؛ زبانی که
خود Emacs از آن برای شخصی‌سازی و گسترش استفاده می‌کند.

به همین دلیل ممکن است دو نفر از Emacs استفاده کنند،
اما محیط و workflow کاملاً متفاوتی داشته باشند.

## Emacs فقط برای کدنویسی نیست

احتمالاً اگر درباره‌ی Emacs سرچ کرده باشی، بیشتر
مثال‌هایی که دیدی مربوط به برنامه‌نویسی بوده.
اما Emacs خودش را به کدنویسی محدود نمی‌کند.

میتونی ازش برای نوشتن متن، یادداشت‌برداری،
مدیریت فایل‌ها، کار با Git، مدیریت پروژه و حتی ایمیل زدن و فیلم دیدن و خیلی چیزای دیگه استفاده کنی.

حتی میتونی کاری کنی که Emacs بخشی از workflow
روزمره‌ات باشه، نه فقط برنامه‌ای که گاهی برای
ویرایش یک فایل بازش می‌کنی.

## پس چرا انقدر عجیب بنظر میاد؟

چون Emacs طوری طراحی نشده که فقط چند دکمه را فشار بدهی
و تمام.

Emacs یک سیستم نسبتاً بزرگ و قابل گسترش است و خیلی از
چیزهایی که در ابتدا عجیب به نظر می‌رسند، بعد از مدتی
تبدیل به ابزارهای قدرتمند می‌شوند.

و دقیقاً به همین دلیل است که قرار نیست در این آموزش
همه‌چیز را یک‌جا یاد بگیریم.

## قرار است چطور یادش بگیریم؟

این آموزش قرار نیست یک لیست طولانی از commandها باشد
که حفظشان کنی.

هر چیزی که یاد می‌گیریم قرار است یک دلیل داشته باشد و
تا جای ممکن همان لحظه در خود Emacs امتحانش کنیم.

ممکن است بعضی چیزها را اول متوجه نشوی. کاملاً طبیعی است.
Emacs از آن برنامه‌هایی نیست که لازم باشد از همان روز
اول همه‌ی مفاهیمش را بفهمی.

## یک قدم جلوتر

فعلاً لازم نیست چیزی از Emacs بلد باشی.

در درس‌های بعدی کم‌کم با محیط Emacs، فایل‌ها،
bufferها، commandها و روش کار خود Emacs آشنا می‌شویم.

هدف این نیست که فقط بگویی «Emacs را بلدم».
هدف این است که کم‌کم به جایی برسی که بتوانی
workflow خودت را با آن بسازی.
